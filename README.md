# Happy Teachers Day

A static Teachers' Day greeting page with a photo gallery.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

After pushing this repository to GitHub, open **Settings → Pages** and deploy from the `main` branch, using the `/ (root)` folder. The published site will be available at:

`https://<your-github-username>.github.io/<repository-name>/`
